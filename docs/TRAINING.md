# TRAINING.md — Day-10 Staff Training Script

30-minute on-site script, run after install + printer calibration + masters import.

## Script

1. **Login** — show the user/PIN screen, explain roles (Admin vs Staff).
2. **Make a bill** — scan or search an item, add qty, show inclusive-MRP price
   auto-fill, apply a discount, show old balance → new balance, select a payment
   mode, save.
3. **Hold a bill** — start a second bill, park it mid-entry (a customer walks in
   during rush hour), show it sitting in the Held list.
4. **Recall the held bill** — reopen it, finish it, save.
5. **Cancel a bill** — cancel the bill made in step 2, show stock reverses and the
   invoice number stays visible as "Cancelled" (never deleted — explain why: GST
   filing needs a gap-free number series).
6. **Print a label** — pick an item, print one of the 3 label templates, confirm
   barcode scans back correctly.
7. **Day report** — open the Sales report for today, show Print / PDF / Excel
   buttons, generate one of each.
8. **Low stock alert** — show the dashboard alert list.

## Leave-behind: one-page cheat sheet

- How to make a bill / hold / recall / cancel
- How to print a label
- How to run the day-end sales report
- Who to call for support, and what the trial/subscription expiry looks like when it happens
- Where the Phase 2 request list lives (so the customer knows "can you also add…" has a real home — see [PHASE2.md](PHASE2.md))
